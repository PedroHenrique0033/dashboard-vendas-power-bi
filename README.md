# 📊 Dashboard de Vendas - Power BI

## 📌 Sobre o projeto

Dashboard interativo desenvolvido no Power BI com o objetivo de analisar indicadores importantes de vendas e auxiliar na tomada de decisões através da visualização de dados.

## 📊 Indicadores analisados

- 💰 Faturamento Total
- 📈 Lucros
- 🛒 Total de Pedidos
- 👥 Total de Clientes
- 📅 Faturamento por mês
- 🏆 Top 5 produtos
- 📊 Faturamento por categoria
- 🌎 Faturamento por região
- 🔎 Filtros por produto e ano

## 🛠️ Ferramentas utilizadas

- Power BI
- Power Query
- DAX
- Git
- GitHub

## 📂 Estrutura do projeto

O projeto foi salvo no formato PBIP (Power BI Project), permitindo o versionamento dos arquivos através do Git e GitHub.

## 🚀 Como abrir o projeto

1. Clone este repositório
2. Abra a pasta do projeto
3. Abra o arquivo `.pbip` utilizando o Power BI Desktop
